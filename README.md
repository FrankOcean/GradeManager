## 学生成绩管理系统（前端版）

这是一个纯前端（HTML + CSS + JavaScript）实现的学生成绩管理小系统，用于课堂或小规模场景下的成绩录入与统计。

### 功能特点

- **基本信息管理**：录入 / 编辑 / 删除学生信息（姓名、学号），系统自动生成自增 `ID` 作为主键，避免使用姓名或学号作为主键。
- **灵活的成绩结构**：
  - 支持配置多个成绩项目（如实验成绩、平时成绩、期末笔试成绩等），每个项目都有自己的权重，所有权重之和建议为 100。
  - 支持将某个项目设置为「可拆分」，例如把「实验成绩」拆分成「实验1、实验2、实验3……」，各子项内部也有各自的权重（总和建议为 100）。
  - 权重配置可在页面中直接修改，修改后自动保存在浏览器本地数据库中。
- **成绩计算规则**：
  - 所有分数均以 0–100 分录入。
  - 每个项目按「分数 / 100 × 项目权重」折算，最后所有项目加和为总成绩。
  - 对于可拆分项目（如多次实验），先在内部按子项权重折算出一个 0–100 的综合成绩，再乘以该项目的总权重。
- **排序与查询**：
  - 支持按姓名、学号、总成绩、手动排序序号进行排序，可选择升序/降序。
  - 每个学生可以填写一个「手动排序序号」，数值越小在列表中越靠前，可用于自定义排名。
  - 支持按姓名/学号关键字过滤列表。
- **数据存储**：
  - 使用浏览器内置的 **IndexedDB** 作为轻量级数据库，无需任何后端服务。
  - 即使离线或无外网，只要浏览器支持 IndexedDB，数据也会保存在本机浏览器中。
  - 未引入任何第三方库，部署时只需把本目录的静态文件放到任意静态服务器或直接用浏览器打开 `index.html` 即可。
- **导出导入数据**：
  - 导出为excel或者json文件
  - 也可手动导入excel和json

### 运行方式

- 直接在支持 IndexedDB 的现代浏览器（Chrome、Edge、Safari、Firefox 等）中打开 `index.html`。
- 若在本地文件环境下浏览器有安全限制，推荐使用任意静态服务器（如 `python -m http.server` 或 VSCode / Cursor 自带的静态预览）打开本目录。

### 目录结构

- `index.html`：主页面，包含成绩结构配置、学生录入表单与列表展示。
- `styles.css`：页面样式，简洁现代风格的响应式布局。
- `app.js`：前端逻辑，包括 IndexedDB 数据库封装、成绩结构管理、成绩计算与排序等。
- `README.md`：项目说明。
